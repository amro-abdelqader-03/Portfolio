# Amro Abdelqader | Portfolio

Responsive personal portfolio for Amro Abdelqader, a Full-Stack Developer and AI enthusiast. The site presents his background, experience, technical skills, selected projects, CV, and contact details.

## Live Links

- [View the portfolio](https://amro-abdelqader-03.github.io/Portfolio/)
- [View the Figma design](https://www.figma.com/design/6FVo2wefZZIr9PCHhe8Tm1/PROTOFILO?node-id=0-1&t=QZKRFMgiYHRJR3hD-1)
- [GitHub profile](https://github.com/amro-abdelqader-03)

## Features

- Responsive portfolio layout for desktop and small screens
- Sections for about, projects, skills, experience, education, and contact
- Separate page listing all projects
- CSS-only light and dark theme toggle
- CSS animations and smooth scrolling
- CV download link and external social links

## Built With

- HTML5
- CSS3
- Bootstrap 5 via CDN

## Run Locally

No backend, package manager, or build step is required.

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension for a local preview.

The full project list is available at `projects.html`.
